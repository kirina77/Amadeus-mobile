## 装之前

- 安卓 **7.0 及以上**（`minSdk 24`），**arm64-v8a**；32 位机器装不了。
- 安装包 899 MB，装完约 1.1 GB，**留 3 GB 空闲**。
- 手机端要配一个电脑端才算完整（人格、记忆、语音都在那边）。不想连电脑的话，看源码包里的 `交付手册/附录A-自建服务路线.md`。
- 发出去的这一包是**空记忆**的干净起点：没有任何人的记忆、照片、API key。装完能聊天、出声、看立绘、收提醒；「她记得你自己的事」需要你按 `交付手册/02-手机端.md §4.2` 用工具重编一次。

## 装

1. 下 `amadeus-clean-<版本>.apk`，点安装（系统提示「未知来源」时允许即可）。
2. 打开 App → 设置 → 连接电脑：同一局域网下扫电脑端给出的配对码。
3. 首次连上后，进设置页按一次「同步人格（从电脑）」，人设与记忆才真正落地。
4. 换版本：**同签名的包可以直接覆盖安装**，聊天记录与钥匙都留着。只有提示「签名不一致」时才需要先卸载——卸载会清数据，先备份。

## 校验下载

Windows：

```
certutil -hashfile amadeus-clean-v9.0.407.apk SHA256
```

Linux / macOS：

```
curl -LO https://github.com/kirina77/Amadeus-mobile/releases/latest/download/SHA256SUMS.txt
sha256sum -c SHA256SUMS.txt
```

比对 `SHA256SUMS.txt` 里的值。对不上说明文件传坏了或被换过，别装。
